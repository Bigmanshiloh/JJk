# Jujutsu Kaisen: Cursed Legacy

A standalone fan-made browser RPG set in 2006 during the student era of Satoru Gojo and Suguru Geto.

## GitHub Pages
Upload the contents of this folder to a repository and enable GitHub Pages from the repository's Pages settings. `index.html` is the entry point.

## Features
- Character creation: name, clan, cursed technique, trait
- Spring / Summer / Autumn / Winter story chapters
- Overworld exploration
- Turn-based combat
- Grade 4 through Special Grade enemies
- Boss phases and final Legacy User encounter
- Technique-specific abilities
- XP, levels and skill tree
- Reverse Cursed Technique, Simple Domain, Maximum Technique and Domain Expansion progression
- Local save slots
- Auto-save to Slot 1
- JSON save export/import
- Responsive Chromebook/mobile layout
- No emulator, server, database or build step

Fan-made project; not affiliated with or endorsed by the Jujutsu Kaisen rights holders.
